# SUROB MSI Calculator

Field-test calculator for the SUROB worksheet (A–H) with final Modified Surf Index and craft GO / NO-GO status.

**Open it:** https://wardenofthekeys.github.io/SUROB/

Works on phone or desktop. On iPhone: open in Safari → Share → *Add to Home Screen* for app-style use.

> Training aid. Validate against current command guidance before operational use.
