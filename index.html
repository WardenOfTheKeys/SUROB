Human decision (required)

The calculator only compares entered values with listed limits. It never makes, recommends or sends a GO / NO-GO decision. The responsible person records the decision here. If any input changes afterwards, the decision is flagged for re-confirmation.

9. Human control and tools used

Human control

  • Approval point: only a named decision authority records GO, GO with restrictions or NO-GO in section 8. The app starts every observation as PENDING.
  • Prohibited actions (enforced in code): the app does not choose a decision, send data or contact any other site. A Content-Security-Policy blocks every request except its own icon and install manifest, and nothing typed into the app is ever sent. It asks for no names or other PII.
  • Monitoring: input warnings, the workflow verification block, and a re-confirm flag whenever inputs change after a decision.
  • Escalation: any red warning, any at-limit or exceeded craft, or any mismatch with the paper worksheet goes to the BPTC or SRM. The paper worksheet is the reference.
  • Shutdown: close the tab. Clear form erases the data saved on this device. There are no background services, accounts or servers.

Tools and resources used

  • Claude Code desktop app with the Anthropic Claude Opus 5.5 model, used to write and review code.
  • A command-line shell for file checks, and the Claude Code built-in browser preview for testing.
  • No external libraries, APIs, datasets or cloud services at runtime. It is a single offline HTML file.
  • MSI tables were carried over unchanged from the original worksheet version. The team must cite the source worksheet or publication.
